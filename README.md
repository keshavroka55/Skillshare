# SkillShare Web App

A simple **Skill Sharing and Networking web application** built as the **final project of my Django learning journey**. This project goes beyond just implementing concepts and represents a **summary of all the classes and lessons I have learned**.

---

## Features

- Create and share your skills or knowledge  
- Find and connect with people who want to learn or share skills  
- User authentication (registration and login)  
- **Continue with Google** login using Django Allauth  
- Follow, message, or connect with other users (like LinkedIn connections)  
- Simple and clean user interface  

---

## Tech Stack

- **Backend**: Django  
- **Database**: SQLite  
- **Templates**: Django Templates  
- **Styling**: CSS / Bootstrap  
- **Authentication**: Django Allauth (Google OAuth)  
- **Deployment**: Render
